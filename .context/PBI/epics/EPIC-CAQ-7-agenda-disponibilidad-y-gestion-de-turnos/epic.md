# Epic: [Epic] Agenda, disponibilidad y gestión de turnos

**ID:** CAQ-7
**Estado de sincronización:** Sincronizado con Jira (`CAQ`)
**Estado:** To Do

## Descripción

Permitir que el profesional defina cuándo atiende, establezca una duración estándar, bloquee períodos y consulte o registre turnos desde su agenda. El alcance proviene de `.context/architecture/prd.md` · Feature 2 y de `.context/Confluence-corporativo/03-especificacion-funcional-v0.3.md` · secciones 2.1 y 4.

## User Stories

- [ ] CAQ-11: Como profesional, quiero configurar mi disponibilidad semanal, para ofrecer únicamente los horarios en los que atiendo.
- [ ] CAQ-12: Como profesional, quiero definir la duración estándar de mis turnos, para generar horarios acordes con mi servicio.
- [ ] CAQ-13: Como profesional, quiero bloquear períodos puntuales, para evitar reservas cuando no estoy disponible.
- [ ] CAQ-15: Como profesional, quiero consultar mis próximos turnos, para organizar mi jornada.
- [ ] CAQ-14: Como profesional, quiero registrar un turno manualmente, para incorporar reservas coordinadas fuera de la página pública.

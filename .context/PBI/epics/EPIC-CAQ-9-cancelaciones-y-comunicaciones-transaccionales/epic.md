# Epic: [Epic] Cancelaciones y comunicaciones transaccionales

**ID:** CAQ-9
**Estado de sincronización:** Sincronizado con Jira (`CAQ`)
**Estado:** To Do

## Descripción

Permitir que cliente y profesional cancelen turnos futuros, liberar el horario y mantener informadas a las partes mediante correos de reserva, cancelación y recordatorio. El alcance proviene de `.context/architecture/prd.md` · Feature 4 y de `.context/Confluence-corporativo/03-especificacion-funcional-v0.3.md` · secciones 6 y 7.

## User Stories

- [ ] CAQ-20: Como cliente final, quiero cancelar mediante el enlace de mi correo, para liberar el horario sin crear una cuenta.
- [ ] CAQ-21: Como profesional, quiero cancelar un turno desde mi panel, para actualizar mi agenda.
- [ ] CAQ-22: Como parte de un turno cancelado, quiero recibir un aviso, para conocer el cambio.
- [ ] CAQ-23: Como participante de una reserva, quiero recibir su confirmación por correo, para conservar los datos del turno.
- [ ] CAQ-24: Como cliente final, quiero recibir un recordatorio el día anterior, para reducir el riesgo de olvidar el turno.

# Epic: [Epic] Página pública y auto-reserva

**ID:** CAQ-8
**Estado de sincronización:** Sincronizado con Jira (`CAQ`)
**Estado:** To Do

## Descripción

Permitir que un cliente acceda a la página pública de un profesional, consulte horarios y confirme una reserva sin crear una cuenta, incluyendo el manejo de conflictos concurrentes. El alcance proviene de `.context/architecture/prd.md` · Feature 3 y de `.context/Confluence-corporativo/03-especificacion-funcional-v0.3.md` · sección 5.

## User Stories

- [ ] CAQ-17: Como cliente final, quiero acceder a la página pública de un profesional, para identificar con quién voy a reservar.
- [ ] CAQ-16: Como cliente final, quiero consultar los horarios disponibles, para elegir una opción conveniente.
- [ ] CAQ-18: Como cliente final, quiero confirmar un turno sin crear una cuenta, para reservar con la menor fricción posible.
- [ ] CAQ-19: Como cliente final, quiero conservar mis datos si otro cliente toma el horario, para elegir otro sin comenzar de nuevo.
